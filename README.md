# Coleta Mais

**Projeto de Programação Linear para otimização da coleta de resíduos.**

## Sobre o projeto

O **Coleta Mais** é um projeto acadêmico desenvolvido com foco na aplicação de **Programação Linear** a um problema relacionado à coleta de resíduos.

A proposta é utilizar técnicas de modelagem matemática para representar as restrições e objetivos do problema, permitindo analisar diferentes possibilidades de operação e buscar uma solução otimizada.

## Objetivo

Desenvolver um modelo matemático capaz de apoiar a tomada de decisão na coleta de resíduos, considerando as características e restrições definidas para o problema.

Entre os principais pontos do projeto estão:

- Modelagem do problema de coleta;
- Definição das variáveis de decisão;
- Definição da função objetivo;
- Definição das restrições;
- Aplicação de Programação Linear;
- Análise dos resultados obtidos.

## Tecnologias e conceitos

- Programação Linear;
- Otimização Matemática;
- Modelagem de problemas;
- Algoritmos de otimização;
- Desenvolvimento de software.

> As tecnologias utilizadas na implementação podem ser adicionadas conforme a evolução do projeto.

## Identidade visual

A identidade do **Coleta Mais** utiliza uma abordagem minimalista, com:

- Caminhão de coleta visto de lado;
- Frente do caminhão direcionada para a direita;
- Silhueta do estado de São Paulo aplicada na lateral;
- Paleta predominantemente verde;
- Fundo branco;
- Tipografia limpa e moderna.

A marca representa a relação entre **coleta, organização, sustentabilidade e atuação no estado de São Paulo**.

## Projeto acadêmico

O **Coleta Mais** foi desenvolvido como um projeto acadêmico relacionado à disciplina/conteúdo de **Programação Linear**, tendo como foco a aplicação prática de conceitos de otimização em um problema do mundo real.
